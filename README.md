C# Backend Blueprint:
- .NET 8
- CQRS MediatR
- EF Framework

Preparation
- install mssql server 
- navigate to NET.Backend.Blueprint.Api
- Visual Studio > View > Terminal > dotnet ef database update 
- appsettings > enable "BlueprintDatabaseTest" as Database
- run in cmd "dotnet ef database update" again to create integration test database
